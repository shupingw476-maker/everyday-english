# 请叫我学习

两个人互相监督的学习站：记单词（间隔重复）、做题、每日打卡。一个人创建房间，把 6 位邀请码发给朋友；两个人都能看到对方今天有没有打卡。昨天没打卡的人，第二天要多做一份惩罚任务，同伴打开网站时也会看到催促提醒。

默认学大学英语四级。学习计划记在每个人自己身上，不是第二个房间：可以改成韩语入门，或四级英语加韩语。房间仍然只有两个人。

不需要手机号，也不连接微信。数据保存在这台学习站的服务器里（SQLite），浏览器只记住你的登录凭证。

## 怎样在电脑上运行

需要 Python 3.10 或更高版本。

```bash
cd everyday-english
python3 -m venv .venv
source .venv/bin/activate    # Windows 用 .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

也可以直接运行：

```bash
./run.sh
```

然后在浏览器打开 <http://127.0.0.1:8765/> 。

两个人要在不同设备上一起用，需要让对方也能访问这台电脑的地址，例如同一局域网里的 `http://192.168.x.x:8765/`。如果要在公网（尤其是国内网络）稳定访问，需要另外把这个网站部署到可访问的服务器，本项目还不包含上线托管。

默认端口是 `8765`，可以用环境变量修改：

```bash
JINBU_PORT=8080 python app.py
```

## 两个人怎么加入

1. 一个人打开网站，选择「创建房间」，填写自己的昵称，可选填朋友的名字，也可以改「惩罚约定」。
2. 页面上会出现 6 位邀请码，把它发给朋友（例如用微信发送）。
3. 朋友打开同一个网站地址，选择「加入房间」，输入邀请码和自己的昵称。
4. 一个房间最多两个人。如果有人换了手机或清掉了浏览器数据，用**同一个邀请码 + 当时的昵称**就可以回到原来的进度。

## 打卡与惩罚

打卡按 **Asia/Shanghai（北京时间）** 的自然日计算。

打卡按这个人自己的学习计划计算。四级英语要先完成当天到期的复习，再完成新词（默认 20 个，可在设置里改），然后做完 1 组 10 道题。韩语同样先复习、再完成 8 个新词，并做完 1 组 6 道小测。两门都开着时，两门都做完才算打卡；韩语进度不会算进英语，英语也不会算进韩语。首页会写明今天必须完成的项目。

## 怎么记住

英语和韩语用同一套记忆规则。一个词在本轮里要点「认识」满 **3 次**才算过关；「不认识」把这 3 次清零，「模糊」减掉 1 次。卡片上会显示 `2/3` 这样的进度，不能点一次就翻篇。以前按 5 次来记、已经认出 3 次或 4 次的词，现在直接算过关，不用再补到 5 次。

过关之后按艾宾浩斯曲线安排下一次复习，间隔是北京时间的自然日：**1、2、4、7、15、30 天**。新词的 3 次回忆就在当天完成，第一次间隔复习是第二天。已经到 30 天的词，下次仍是 30 天。复习时如果选了「不认识」，间隔退回上一级（30 退到 15，15 退到 7，以此类推，最短停在 1 天），不会继续变长。

练英语单词时要拼写。卡片先给出中文意思和朗读，并显示单词开头：超过 3 个字母给出前 3 个，例如 accept 显示 acc；3 个字母及以内只给第 1 个字母。可以接着写剩下的字母，也可以输入整个单词。大小写不区分，多余空格不算错。拼对会记为一次「认识」，同一次卡片不会再加一遍。拼错会写明正确拼写，然后再选「认识」「模糊」或「不认识」。答完后仍能看音标、听朗读、读例句。韩语卡片仍是翻面回忆意思，不要求用英文字母拼写。

每天的复习来自这条曲线上到期的词，排在新词前面，做完才能打卡。新词仍有每天的上限。一天里要求完成的复习不超过设置里的复习上限（韩语是 24 个），多出来的继续留在后面的日子里。已经记下的到期日、积分、连续打卡和单词进度会保留；旧的间隔会就近收进这条曲线，不会把学过的词清成新词。

若某一天结束时还没打卡，第二天会：

- 连续学习天数清零
- 本人显示「欠打卡」，并且当天要在自己正在学的每一门上多做一份惩罚任务（英语是额外 20 个新词 + 一组题，韩语是额外 8 个新词 + 一组小测），完成这些连同平时任务后才能重新打卡
- 同伴打开网站时，会看到很明显的横幅，例如「小红昨天没打卡了，按约定去催一下！」并附上房间里的惩罚约定
- 若已打开浏览器通知，打开网站时也会收到一次提醒（每天一次，只发给这两个人的浏览器，不会发到别处）

如果两个人都没打卡，就都会看到对方的提醒，也都会领到惩罚任务。

## 读音、造句和答对奖励

记单词时，卡片上会标出「读音」和「造句」。做词汇题时也有「读音」和「朗读」：题干本身就是单词的（英选中、韩选中），答之前就能看音标、听读音，答完之后按钮还在；要选出单词的题（中选英、填空、中选韩），每个单词选项都有音标和朗读，答完后正确单词会再单独显示读音，也可以再听一遍。语法题不标读音。英语有国际音标（词库里有的才显示）和例句、中文翻译；原来没有例句的词，会补一句简单例句，不会留空。韩语显示韩文和修订罗马字，以及一句短例句和中文。点「朗读」可以听这个词：优先用浏览器的 Web Speech API（英语 `en-US`，韩语 `ko-KR`）；微信里或当前设备没有对应语音时，改由本站向有道、百度的朗读接口要一段音频再播放。

做题答对一次记 15 分（原来的 10 分，再加 5 分奖励），并出现一个短暂的金色「答对了」动画。答错不加分，也没有这个动画。

## 四级词库来源

本站词库是公开的四级教学数据整理结果，**不是**新东方、星火等商业单词书的原文抄录。

- 词条与中文释义、音标：主要依据 [mahavivo/english-wordlists](https://github.com/mahavivo/english-wordlists) 中的 `CET4_edited.txt`。作者说明该表整理自大学英语四级大纲词汇，并对音标做了校对。
- 2016 年大纲增补词、词频排序与完整例句：来自 [exam-data/CETVocabulary](https://github.com/exam-data/CETVocabulary) 的 `cet_full_list.json`。该数据集依据《全国大学英语四、六级考试大纲（2016 年修订版）》整理，本站只收入其中的四级词（不含标记为六级的词条）。许可证为 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)。
- 处理原则：两个来源做合并去重；只保留完整的英文例句，短语片段会省略，避免编造不准确的句子；音标尽量保留公开列表中的记法。

当前内置约五千个四级词条，以及 90 多道四级风格语法题。词汇练习题由词库现场生成（英选中、中选英、例句填空），每次 10 题会打乱组合，不会固定同一套。

## 韩语词库来源

韩语和英语词库分开存放，进度也分开记。入门词取自国立国语院《韩国语基础词典》（한국어기초사전）公开数据，经 [basickorean/basickorean-vocab](https://github.com/basickorean/basickorean-vocab) 整理，许可证为 [CC BY-SA 2.0 KR](https://creativecommons.org/licenses/by-sa/2.0/kr/)。本站只收入其中标为国际通行韩国语标准教育课程 **1级** 的词（约八百个），中文词义用这份数据里的中文释义；读音按词形生成修订罗马字。例句是为本站写的短句，不是从商业教材抄来的。详见 `data/SOURCE.md`。

已经在用的房间不会被清空。服务启动时，如果成员昵称是 `koo陸_`（下划线、空格或简繁写法略有差别也会认），会在他原来的四级计划上加上韩语，变成「四级英语 + 韩语」。其他人保持四级英语。这件事只做一次，之后在设置里改计划不会被下次启动改回去。新加入的人默认仍是四级英语。

## 数据备份

学习记录在服务器的 `var/jinbu.db`。请定期在「设置」里导出 JSON 备份；换设备前也可以导出，再在同一房间里导入到自己的账号。

「退出本机登录」只清除这台浏览器里的凭证，不会退出房间。「重置」只清空你自己的进度，不影响同伴。

## 自己改内容

- 四级词库：`data/cet4_words.json`（字段：`id / word / ipa / meaning / example / exampleZh`）
- 韩语词库：`data/korean_words.json`（另有 `lang / reading`；可用 `scripts/build_korean_bank.py` 从上面的公开数据重新生成）
- 语法题：`data/grammar.json`（`answer` 是选项序号，从 0 开始）
- 也可以在应用里添加只属于自己的自定义单词

## 部署到帽子云

这是一个带后端的 Web 应用（FastAPI + SQLite），请用「新建 → Web 服务」，不要选静态网站。

推荐配置：

- 部署来源：Git 仓库，构建类型选 Dockerfile（仓库根目录已包含 `Dockerfile`）
- 启动端口：容器内监听 `8080`
- 计算资源：可选最小规格（约 0.5 核 / 512Mi）
- 持久卷：必须添加，名称例如 `data`，容量 1 GiB 即可，挂载路径填 `/data`（打卡和单词进度保存在这里，没有持久卷的话，容器一重启数据会丢）

创建房间后，把邀请码和网站地址一起发给朋友，两个人打开同一个地址即可互相监督。
